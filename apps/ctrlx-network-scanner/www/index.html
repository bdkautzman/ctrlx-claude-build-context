        Whitelist and blacklist

        The lists rate scan results, they don't limit what is scanned. Whitelist = expected, blacklist = forbidden (counted as alarm, also in the Data Layer node last/alarms), neither = not listed. The blacklist wins.
        Hosts: IP, network, range, MAC address, MAC prefix (00:60:34 = one vendor), name pattern (plc-*) - empty = all hosts. Ports: 502, tcp/22, udp/161, tcp/8000-8100 - empty = the entry rates the hosts themselves.
