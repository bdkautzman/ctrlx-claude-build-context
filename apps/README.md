# apps

Create apps here with:

    python3 tools/new_app.py --name ctrlx-<company>-<app> --title "<Title>" --author "<Company>" --url <url>

Each app folder can also become its own git repository.

| App | What | Status |
|---|---|---|
| `ctrlx-core-connector` (until 0.1.x `ctrlx-core-monitor`) | This device and other ctrlX COREs: status tiles (host name, IP, firmware, operating state, CPU, memory) via Data Layer remote connections; Data Layer browser per core (tree, values, metadata, write); Key Value Database nodes add/delete (nodes.json, locally or via the core's WebDAV); home screen widget with the operating states; settings drawer | 0.2.4 - 2026-11-01 on both devices (browser read interval setting, "Editable" + person icon for KVD nodes, tutorial card/ring placement, KVD collection details fix); 0.2.3 - 2026-10-31 on both devices (help button: GitHub page + tutorial over both pages); 0.2.2 (status values optional: a ctrlX OS 3.6 core without system/info host name/uptime); 0.2.1 - 2026-10-31 on both devices (counts incl. this device, names with capitals, port in the host field); 0.2.0 - 2026-10-31: amd64 on the COREvirtual and arm64 on the real CORE, each browsing/writing the other and adding/deleting KVD nodes on itself and the other (details in its CHANGELOG); 0.1.1 verified 2026-10-22 |
| `ctrlx-amr-fleet` | Live map of AMRs: positions/headings written to the Data Layer - one JSON string for the fleet (`ctrlx-amr-fleet/fleet/amrs`), one per AMR or one node per value and AMR (`fleet/amr/<id>/...`, AMR list in the app data; setting `fleet.input`); occupancy map (bundled `HMI_Map.txt` or app data) as tiles; map chosen in a drop-down of the app data and bundled maps, upload button; pan, zoom, pinch, lock (heading-up), minimap, AMR list with detail tiles; driven paths per AMR; help menu with GitHub link and tutorial; styling settings; read-only users without settings; ctrlX home screen widget; simulation with collision avoidance | 0.5.0 (map drop-down + upload, smaller simulation grid) installed on the COREvirtual 2026-11-02: a 208 x 356 m warehouse map (8.7 MB) uploaded with the button through the reverse proxy, loaded in 0.7 s, app 60.6 MB - 0.4.0 (input modes, AMR list) installed on the COREvirtual and the real CORE 2026-11-01: per-AMR nodes checked through REST on the COREvirtual, input-mode load test on both (README) - 0.3.0 (paths, help, tutorial) installed on the COREvirtual and the real CORE 2026-10-24: checked on the COREvirtual (API, ui_check --device), memory/load re-measured on the CORE (README) - 0.2.4 installed on the COREvirtual (amd64) and the real CORE (arm64) on 2026-10-24 and performance-tested before/after (0.2.2) with a 103 x 177 m map and 10-200 simulated AMRs on both (results in its README); app, ui_check --device and home screen widget verified on the COREvirtual (0.2.0) |
